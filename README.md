# DevisChat

App iPhone en forme de chat pour fabriquer des devis BTP, avec un petit serveur Python
qui parle à l'IA et produit les fichiers Word/PDF.

> README en cours de rédaction (phase 0). La version complète arrive en fin de mission.

- `server/` : serveur FastAPI (IA, rendu Word/PDF)
- `ios/` : app SwiftUI (projet généré par XcodeGen)
- `shared/fixtures/` : devis d'exemple utilisés par les tests serveur ET iOS
- `docs/` : documents pour le patron et pour l'installation sur iPhone
